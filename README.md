# 🇦🇴 Prodigy Kamba IA — A Infraestrutura de IA de Angola

**Prodigy Kamba IA** é uma plataforma e infraestrutura soberana de Inteligência Artificial desenhada especificamente para empresas, comércio global, PMEs e líderes em Angola.

---

## ✨ Funcionalidades Principais

- ⚡ **Design System Moderno (Vercel-inspired)**: Tipografia Geist/Geist Mono, paleta de alta definição inspirada na Palanca Negra e bandeira nacional (Preto, Vermelho e Dourado).
- 💬 **Chat IA em Tempo Real com Streaming**: Respostas inteligentes contextualizadas para a realidade angolana (mercado de Luanda, INAPEM, expansão B2B, logística e comércio exterior).
- 📊 **Terminal / App Preview Interativo**: Simulações com tabs dinâmicas no hero (Mercado Luanda, Proposta INAPEM, Expansão B2B).
- 📱 **100% Responsivo**: Otimizado para desktop e dispositivos móveis (drawer menu, layout dinâmico adaptável).
- 🛡️ **Autenticação e Modos de Acesso**: Tela de login com suporte a modo demonstração direto.

---

## 🚀 Como Executar Localmente

Como o projeto é construído com tecnologias web nativas (HTML5, CSS3 puro e JavaScript moderno), não requer instalação de dependências pesadas:

1. Clone o repositório:
   ```bash
   git clone https://github.com/brunosouzamelo1999/prodigy-kamba-ia.git
   cd prodigy-kamba-ia
   ```

2. Inicie um servidor local simples:
   - **Com Python**:
     ```bash
     python -m http.server 8085
     ```
   - **Com Node.js (npx serve)**:
     ```bash
     npx serve .
     ```

3. Abra no navegador:
   ```
   http://localhost:8085/
   ```
