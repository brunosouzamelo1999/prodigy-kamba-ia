# ✨ Kamba Chat IA — Assistente de Inteligência Artificial Conversacional

**Kamba Chat IA** é uma aplicação web interativa de inteligência artificial de uso geral (no estilo ChatGPT / Claude / Gemini), desenhada para ser rápida, acessível e fluida em **qualquer dispositivo**: na palma da mão (smartphone), no tablet e no computador.

## ✨ Principais Funcionalidades

- 💬 **Livre para Qualquer Assunto:** Não está preso a nichos corporativos. Converse sobre programação, redação criativa, estudos, física, culinária, produtividade ou diálogos do cotidiano.
- 📱 **Multi-Dispositivo de Alto Nível:**
  - **Smartphone (Na Palma da Mão):** Ergonomia focada no polegar, carregamento instantâneo e baixo consumo de dados móveis.
  - **Tablet:** Leitura imersiva com tipografia espaçosa, ideal para estudos e anotações.
  - **Computador (Desktop):** Atalhos rápidos (`Enter` para enviar, `Shift+Enter` para quebra de linha), blocos de código com destaque e cópia rápida.
- ⚡ **Efeito Streaming em Tempo Real:** As respostas surgem dinamicamente caractere por caractere com cursor piscante, simulando o pensamento da IA.
- 📝 **Markdown Rico & Formatação de Código:** Suporte a cabeçalhos, listas destacadas, citações e blocos de código monoespaçados.
- 🗂️ **Histórico Salvo & Busca em Tempo Real:** Suas conversas ficam salvas com segurança no navegador com filtro instantâneo por palavras-chave.
- 🎨 **Design System Moderno (Vercel Style):** Dark mode com acabamento refinado, tipografia Geist e iluminação radiante.

## 🚀 Como Executar Localmente

Construído com tecnologias nativas (HTML5, Vanilla CSS3 e JavaScript modular):

1. Clone o repositório:
   ```bash
   git clone https://github.com/brunosouzamelo1999/prodigy-kamba-ia.git
   cd prodigy-kamba-ia
   ```

2. Inicie o servidor local simples com Python:
   ```bash
   python -m http.server 8085
   ```

3. Abra no seu navegador:
   ```
   http://localhost:8085/
   ```
